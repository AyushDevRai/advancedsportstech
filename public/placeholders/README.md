# Replaceable AST media

The JPG files are downloaded copies of AST's own existing website media, used as replaceable review assets. Original URLs and descriptive alt text are in `content/media.ts`. No media or code was copied from the design reference.

Phase 2 needs a licensed, silent AST hero video: desktop MP4 and WebM, a lighter mobile MP4, and a matching poster. There is no invented video or broken video source in Phase 1.

`athletics.jpg` is an AST track plan, not a photograph, and is reserved for later technical content.
